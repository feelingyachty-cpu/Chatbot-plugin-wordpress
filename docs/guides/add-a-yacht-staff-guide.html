What this plugin does

Think of it like this

You are not writing a blog post. You are adding one boat to the shop. The plugin copies that boat onto the public site so guests can see it, compare prices, and book.

One yacht = one record

Add the boat once. Do not make a second copy “just in case.” Extra copies confuse guests and split the booking links.

Miami list to use: miami-yacht-rental (no extra “s”). The older list named miami-yacht-rentals is leftover. Do not add new boats there.

Step 2 · WordPress
The main lesson

2 Add the yacht in WordPress

Log in to FeelingYachty.com WordPress. You need permission to edit Yachts. If you do not see Yachts in the left menu, ask a manager.

Open Yachts → Add New

Left menu: Yachts (sometimes under Feeling Yachty / Fleet). Click Add New. You are now making one boat record.

Type the public name

Use the formula: 50ft Pink Maxum “Barbie”. This name shows on the card, the page title, and texts to guests. No HTML codes. No emoji. No “cheap yacht rental Miami” in the title.

Set the featured photo, then the gallery

The featured photo is the catalog card. Use a bright, wide shot of the whole boat. Then add more photos to the gallery so the guest page has a slideshow.

Pick the fleet / city

Miami new boats → miami-yacht-rental.
Panama boats → panama-yacht-rentals (if that box is empty, stop and tell a manager — Panama may still live on older pages).
Do not tick both Miami lists. Do not use the old miami-yacht-rentals list for new boats.

Fill the spec boxes

Length (ft), Max guests, Year, Brand, Model. Turn Captain included on. Turn Pink on only if the boat is truly pink. Turn Free hour on only if the price table has a “pay 4 get 5” style deal.

Guests on a 26–32 ft boat: do not type 13 unless the boat is really licensed for 13. A small boat with “13 guests” looks wrong and can cause a fight at the dock.

2 Prices, marina, then Publish

Enter the price table as totals

Each row is one trip length and the full charter price guests pay for that length. Use a heading row for weekday vs weekend if prices change.

Weekday vs weekend: add a heading row like “Monday–Thursday” then the prices, then a heading “Friday–Sunday” then those prices. A weekend extra can be a note: Weekend surcharge — $150.

Pick the marina

Choose from the marina list (Dinner Key, Miami Beach Marina, Bill Bird / Haulover, and so on). Add a pickup note if guests need a gate or “meet at the white tent.” If you skip this, guests will call you.

Write a short guest blurb

3–5 sentences. Who it is for, what is on board, where it leaves. Do not paste a novel. Do not invent a price in the blurb that does not match the table.

Badges (optional)

Use only if they are true: Pink Yacht, +1 Free Hour, Bachelorette Favorite, Slide Available, New Yacht. Too many badges look like spam.

Click Publish — not Save Draft

Draft is invisible to guests. Publish makes the catalog card and the shop product. Then copy the public link and send it to yourself.

Step 4 · Later edits
After it is live

4 How to change a yacht later

Always edit the same yacht record. Do not add a new yacht to “update” an old one.

Change a price

Yachts → find the boat → edit the price row → Update. Then open the guest card and confirm the new total. If a weekly sheet also pushes prices, tell the person who owns that sheet so you do not overwrite each other.

Change photos

Replace the featured image if the card should change. Add or remove gallery photos for the page. Guests judge the boat in 2 seconds — blurry first photos lose the booking.

Hide a boat for a while

Set status to Draft or unpublish. Do not delete unless a manager says so. Deleting can break old links guests already saved.

Sold, renamed, or moved marina

Edit the same record. Keep the same public link if you can. Changing the name a little is fine. Making a brand-new page loses reviews and old ads.

Quick “is it good?” checklist

  • Name is size + brand + nickname. No duplicate “Azimut” with no nickname.
  • First photo is clear. At least 4 more photos on the page.
  • City/fleet is the current Miami list or Panama — not both Miami lists.
  • Guest count is honest for that size boat.
  • Captain is on, unless it is truly bareboat.
  • Every price is a trip total, not an hourly rate sitting next to “3 Hours.”
  • Marina is filled. You could tell a guest where to stand.
  • You opened the guest page while logged out and the Book button works.
  • You sent the link + 4-hour price + marina in the team chat.

Whole-site controls

Fleets, marinas, badges, shop

These controls change the whole website. Wrong clicks can hide the fleet or break booking messages.

Fleets (cities / lists)

Fleet name you will seeUse it for
miami-yacht-rentalAll new Miami boats. This is the public catalog.
miami-yacht-rentals (older)Leftover list. Do not add new boats. A manager should merge or hide it.
panama-yacht-rentalsPanama boats inside the plugin. If the count is zero, Panama may still be on older pages — do not duplicate them.

Marinas

The plugin keeps a shared marina list (Dinner Key, Miamarina, Bill Bird, Crandon, and many more — about 58). Add a marina here once. Then every yacht can pick it. Do not type a one-off address on each boat if the marina already exists.

Badges

Styles guests see: hot party/value tags, pink Pink Yacht, free +1 Free Hour. Keep the list short. Inventing new badge names every week makes the site look messy.

WooCommerce / Book button

Each published yacht is tied to one shop product. The product page is filled by the plugin (you may see a tiny fy-auto note). Do not empty that product. Do not create a second product by hand for the same boat.

Do not rename fleet slugs

Guest links and filters use those names. Renaming miami-yacht-rental can hide the whole Miami catalog overnight.

Managers only · settings
Office tools & if it breaks

Sync, bookings, and what not to click

Prices that update from a sheet

A weekly automation can push prices from the office Google Sheet into the plugin. If you edit a price in WordPress and it “jumps back,” the sheet won. Change the sheet or WordPress, then tell the team which one is the source of truth.

Bookings and tickets

When a guest pays, the plugin can send a signed message to the office tools (GoHighLevel). That is why paid bookings show up for sales without anyone copying and pasting. Do not rotate secret keys or webhook URLs unless you are the person who set them up.

What you should not click

Do not delete

Fleets, marinas, yachts with old guest links, or the Suite plugin itself.

Do not “test off”

Turning off WooCommerce or Suite kills every Book button on the site.

Do not add another chat

Chat is handled somewhere else on purpose. Do not add a second chat widget here.

Do not invent a second boat

If a listing looks broken, fix the original. A duplicate makes the problem worse.

If something looks broken

1. Confirm the yacht is Published and on the current Miami (or Panama) fleet.
2. Confirm featured photo + at least one price row + marina.
3. Open the guest link logged out.
4. If the page is blank, the shop product may have lost its automatic content — a manager must re-attach it.
5. Still stuck? Send the yacht name, the admin link, and the guest link to the website owner. Do not create a duplicate boat while you wait.
