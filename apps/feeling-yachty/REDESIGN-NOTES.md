# Feeling Yachty UI redesign

This version keeps the existing fleet, booking, saved-yacht, promo, live-contact, and profile behavior while giving the browse experience a new visual hierarchy.

## What changed

- Rebuilt the brand header around the original Feeling Yachty logo, navy, cream, and hot-pink identity.
- Added a more editorial discovery intro with a clearer value proposition and live-service signal.
- Consolidated search into a premium search surface with a quick-clear action.
- Restyled filters as quieter, easier-to-scan controls.
- Reworked yacht cards so photography, title, trip total, capacity, captain status, rating, and pricing controls no longer compete with each other.
- Upgraded featured-yacht reels and recent-yacht cards.
- Rebuilt the bottom navigation as a light, modern tab bar with clearer active states.
- Added English and Spanish copy for the new discovery intro.
- **1.3.3:** Removed the navy letterbox bars on “Add your extras” (image now `cover`s a light frame). Softened yacht detail / card photo placeholders and the sticky book bar. Floating tab bar stays white glass, not navyDeep.

## Verification

The Expo web production bundle completes successfully with the redesigned source.
