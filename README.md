# Feeling Yachty — social command center

This repo is the interior brain for social media, Meta Ads, and Google marketing.

## Open the dash

Open [`dash/index.html`](dash/index.html) in a browser.

You get:

- Today’s AI briefing (read this, not the full internet)
- A link on every article if you want the original
- The publications Pac-Man reads daily
- 10 training homes
- Meta Ads agent notes (Blueprint / Advantage+ / playbook)
- Google Ads + GA4 + Search Console notes
- Ideas to grow Feeling Yachty social
- Ideas to keep this database current
